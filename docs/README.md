# Docs

This folder keeps supporting project documentation that is useful for planning
and architecture, but not required at the repository root.

- `ROLE_DASHBOARD_BLUEPRINT.md` captures the role-based dashboard architecture.
- `DASHBOARD_FEATURES_ROADMAP.md` captures product and workflow planning ideas.
- `PROJECT_ROADMAP_AND_RULES.md` is the working guide for the AI livestock-monitoring goal, current baseline, staged roadmap, and project-specific rules.
